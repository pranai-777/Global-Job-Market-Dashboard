# Global AI Job Market & Skills Demand Dashboard

## 📊 Project Overview
This project analyzes global AI job market trends using real-world job posting data. 
It focuses on skill demand, salary distribution, experience levels, company size, and geographic trends.

## 🧰 Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Streamlit

## 📁 Dataset
- ai_job_dataset.csv
- ai_job_dataset1.csv

## 🚀 Streamlit Dashboard
To run the dashboard locally:

```bash
pip install streamlit pandas matplotlib seaborn
streamlit run app.py

📌 Key Insights

Python and SQL are the most in-demand AI skills

Senior-level roles earn significantly higher salaries

USA and Europe dominate AI job hiring

Remote jobs form a large portion of AI roles
